Project Title: Jamilla Siason — Portfolio Website

Project Description:
The Jamilla Siason Portfolio is a personal website showcasing my skills, creative projects, certificates, resume, and contact information. 
It serves as an online portfolio where visitors can learn more about me, explore my work, and view my achievements.
The website features a modern dark-themed design with pink and purple gradient accents, responsive layouts, and an easy-to-navigate interface. 
It highlights my interests in information technology, programming, web development, graphic design, and digital creativity.

 Features
- Home Section – Displays my name, professional introduction, and navigation menu.
- About Me – Introduces my background and interests as an IT student.
- Skills Section – Showcases my skills in HTML, JavaScript, Canva, and Figma.
- Projects Section – Displays selected creative and digital projects, including product editing, banner design, and portfolio designs.
- Videos Section – Features embedded YouTube videos and learning resources.
- Resume Section – Allows visitors to view my resume.
- Seminar Certificates – Showcases certificates of participation and achievements.
- Contact Section – Provides my email address, phone number, and location information.
- Responsive Layout – Organizes content for different screen sizes.
- Modern UI Design – Uses a dark background, rounded cards, and pink-purple gradient buttons.
- Profile Images – Displays personal photos throughout the website.
- Navigation Links – Allows visitors to move between portfolio sections.

Technologies Used:
- HTML5 – Structures the website and its sections.
- CSS3 – Creates the layout, colors, gradients, animations, and responsive design.
- JavaScript – Supports interactive website features, if implemented.
- YouTube Embed – Displays video content within the portfolio.
- GitHub Pages – Hosts the portfolio website online.

Project Purpose:
The purpose of this project is to build an online professional portfolio that presents my skills, projects, educational achievements, and creative work. 
It also helps me develop my web design and front-end development skills while creating a platform to share my work with others.
